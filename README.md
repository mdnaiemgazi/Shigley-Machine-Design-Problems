
## 🔧 Project Overview

### **Objective**
To solve and simulate problems from *Shigley’s Mechanical Engineering Design* (9th Edition) using **SolidWorks** for:
- **CAD Modeling**: Creating accurate 3D models of machine components.
- **Simulation**: Analyzing stress, motion, and performance.
- **Technical Reporting**: Documenting the design process and results.

### **Key Features**
- **SolidWorks CAD Models**: Parametric designs of machine elements.
- **Dynamic Simulations**: Motion and stress analysis videos.
- **Detailed Reports**: Step-by-step solutions and explanations.
- **High-Quality Images**: Visual documentation of problems and results.

---

## 🛠️ Tools and Software
- **SolidWorks 2023: For CAD modeling and simulation.
- **Git LFS**: For version control of large files (e.g., `.SLDPRT`, `.avi`).
- **MS Office**: For technical report writing (if applicable).

---

## 📂 How to Use This Repository

### **1. CAD Models**
Open `.SLDPRT` and `.SLDASM` files in **SolidWorks** to view or modify the designs.

### **2. Simulations**
Watch `.avi` files in any media player to see dynamic simulations of the designs.

### **3. Reports**
Read the **PDF report** for:
- Problem statements from Shigley’s book.
- Step-by-step design and simulation processes.
- Analysis of results.

### **4. Images**
Use the images in the `Assignment/` folder for visual reference:
- Actual problem setups.
- Simulation snapshots.
